# Checklist de entrega

- [ ] Confirmar prazo e regras no Portal do Aluno.
- [ ] Dados reais com proveniência, período, frequência, unidades e limitações.
- [ ] Pergunta, EDA, indicadores e dois modelos avaliados sem vazamento temporal.
- [ ] Notebook executado ou PDF (até 10 páginas) + script Python.
- [ ] Síntese executiva de uma página.
- [ ] Nomes de todos os integrantes e apenas uma submissão pelo grupo.
